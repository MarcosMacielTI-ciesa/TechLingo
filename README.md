# TechLingo Pro

Projeto React + Vite gerado com o app de glossário, quiz e jogo de memória.

## Comandos

| Comando           | Função                              |
| ----------------- | ----------------------------------- |
| `npm install`     | Instala dependências                |
| `npm run dev`     | Inicia ambiente de desenvolvimento  |
| `npm run build`   | Gera versão otimizada para produção |
| `npm run preview` | Testa a versão final do build       |

voce pode criar as telas de:

Tela Splash;
Tela de Escolha Inicial (ai na tela de escolha coloque um ignorar ai ela vai direto para a tela principal);
Tela de Login;
Tela de Cadastro;
Tela de Recuperação de Senha.
